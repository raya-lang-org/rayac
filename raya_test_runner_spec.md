# Raya Test Runner Specification
## v0.1 — Run `test` Blocks, Report Results

**Status:** Design Ready for Implementation  
**Purpose:** Discover, run, and report `test` declarations in Raya source.

---

## 1. Test Declaration Syntax

```raya
test "parser handles empty input" {
    const result = parse("");
    assert(result.is_ok);
}

test "lexer rejects invalid escape" {
    const result = lex("\q");
    assert(result.is_err);
}
```

**Rules:**
- `test` blocks are top-level declarations.
- Name is a string literal (for filtering and reporting).
- Body is a block. No return type.
- Panic in a test body = test failure.
- Normal exit = test pass.

---

## 2. CLI Interface

```bash
raya test                    # run all tests in project
raya test parser             # run tests matching "parser"
raya test --release-safe     # run with release-safe checks
raya test --sanitizer=memory # run with memory sanitizer
raya test --list             # list tests, don't run
```

## 3. Test Runner Implementation

### 3.1 Discovery

```c
// Walk AST for all test declarations
void test_discover(AstNode *module, TestList *out) {
    for (each decl in module) {
        if (decl->kind == AST_TEST_DECL) {
            test_list_push(out, decl->test_decl.name, decl->test_decl.body);
        }
    }
}
```

### 3.2 Codegen Strategy

For each test, emit a C function:

```c
// Generated by test runner codegen
static void raya_test_parser_handles_empty_input(void) {
    // ... test body lowered to C ...
}

static void raya_test_lexer_rejects_invalid_escape(void) {
    // ... test body lowered to C ...
}

int main(int argc, char **argv) {
    TestResult results[] = {
        { "parser handles empty input", raya_test_parser_handles_empty_input },
        { "lexer rejects invalid escape", raya_test_lexer_rejects_invalid_escape },
        // ...
    };

    int passed = 0, failed = 0;
    for (int i = 0; i < num_tests; i++) {
        pid_t pid = fork();           // isolate each test
        if (pid == 0) {
            // child: run test
            results[i].fn();
            exit(0);                  // no panic = pass
        } else {
            int status;
            waitpid(pid, &status, 0);
            if (WIFEXITED(status) && WEXITSTATUS(status) == 0) {
                printf("  PASS  %s\n", results[i].name);
                passed++;
            } else {
                printf("  FAIL  %s", results[i].name);
                if (WIFSIGNALED(status)) {
                    printf(" (signal %d)", WTERMSIG(status));
                }
                printf("\n");
                failed++;
            }
        }
    }

    printf("\n%d passed, %d failed\n", passed, failed);
    return failed > 0 ? 1 : 0;
}
```

**Why fork per test:** A panic in one test (segfault, abort, assertion failure) must not kill the entire suite.

### 3.3 Assertion Helpers (Runtime)

```c
// raya_rt.h — test assertion helpers

void raya_assert(bool condition, const char *expr, const char *file, size_t line);
void raya_assert_eq_i64(int64_t a, int64_t b, const char *file, size_t line);
void raya_assert_eq_str(const char *a, const char *b, const char *file, size_t line);
```

**Raya syntax sugar (future):**
```raya
test "math works" {
    assert(1 + 1 == 2);
    assert_eq(sum(2, 3), 5);
}
```

For now, users write manual checks that panic on failure:
```raya
test "math works" {
    if (1 + 1 != 2) {
        panic("1 + 1 != 2");
    }
}
```

## 4. Test Output Format

```
Running 14 tests...

  PASS  parser handles empty input
  PASS  lexer rejects invalid escape
  FAIL  sema catches type mismatch (signal 6)
  PASS  codegen emits correct C
  PASS  defer order is LIFO
  FAIL  errdefer runs on error (signal 6)

12 passed, 2 failed
```

**Exit codes:**
- `0` — all tests passed
- `1` — one or more tests failed
- `2` — compilation error (couldn't build test binary)

## 5. Integration with raya.toml

```toml
[test]
# Test-specific build settings
timeout = 30           # seconds per test
parallel = true        # run tests in parallel (fork)
sanitize = ["memory"]  # always run tests with sanitizer

[[test.filter]]
# Skip slow tests by default
skip = ["fuzz_*", "bench_*"]
```
